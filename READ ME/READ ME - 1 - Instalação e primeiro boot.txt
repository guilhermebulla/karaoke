INSTALAÇÃO E PRIMEIRO BOOT — KIT PORTÁTIL
O que mudou: o Node agora viaja DENTRO do kit (node.exe na raiz da
pasta). Não é preciso instalar nada em nenhuma máquina. E o
karaoke.bat funciona em qualquer pasta — não precisa mais ser
C:\karaoke. Pode ficar no Desktop, num pendrive, em qualquer lugar.

O QUE O KIT DEVE CONTER
pasta-do-kit\            (qualquer nome — a sua está em C:\karaoke)
   karaoke.bat           (inicializador)
   server.js             (servidor)
   repertorio.json       (catálogo — já está no GitHub)
   node.exe              (o Node portátil, ~90 MB)
   public\
      index.html         (convidado)
      admin.html         (painel do artista)
      host.html          (painel do host)
      tv.html            (telão)
   READ ME\              (estes guias)

⚠️ Extensões: no Explorador de Arquivos, ative Exibir → Extensões
de nomes de arquivo e confira que os arquivos terminam em .js/.html/
.exe — e não server.js.txt (erro clássico do Bloco de Notas).

PARTE A — MONTAR O KIT (só você faz, UMA vez)
1. Em nodejs.org, baixe o .zip da versão LTS para Windows 64 bits.
2. Abra o .zip, copie APENAS o arquivo node.exe e cole na raiz do
   kit, junto do server.js. (npm e o resto do .zip não são
   necessários: o app usa só recursos internos do Node.)
3. Se existir fila.json de testes, apague — o kit deve sair limpo.
4. Teste em casa: duplo clique no karaoke.bat. O console deve
   imprimir "[CATALOGO] N musica(s) carregada(s)" com N maior que
   zero, e a página do host deve abrir no navegador.

PARTE B — RODAR EM OUTRA MÁQUINA (o host leigo)
1. Copie a pasta INTEIRA do kit (pendrive ou .zip) para o Desktop
   ou para qualquer pasta.
2. Duplo clique em karaoke.bat.
3. A janela "Karaoke do Bulla - servidor" abre e fica aberta a
   festa toda — fechar a janela encerra o app (a fila não se perde).
4. Primeira execução, o Windows pode perguntar:
   - Firewall: clique em "Permitir acesso" (marque as duas caixas
     se elas aparecerem). Acontece só uma vez por computador.
   - "Deseja executar este arquivo?": clique em "Executar".
5. Ligue o hotspot: Configurações → Rede e Internet → Ponto de
   acesso móvel → ative.
6. A página do host abre sozinha, com o endereço dourado dos
   convidados para copiar ou virar QR.

⚠️ O kit é 64 bits: funciona em qualquer Windows atual.

TESTE RÁPIDO (30 segundos, no notebook)
No navegador do próprio notebook:
http://localhost:8080 → página do convidado, com a busca visível;
http://localhost:8080/admin.html → painel do artista (código padrão: bulla2026);
http://localhost:8080/tv.html → telão.
Se as três páginas abrirem, o servidor está pronto.

⚠️ Deixe a janela do servidor aberta o tempo todo. Para parar:
feche a janela ou Ctrl + C. Para reiniciar: duplo clique de novo
no karaoke.bat (a fila sobrevive, fica salva no fila.json).
